Project 1:

Smart Environmental Monitor (Microcontroller Basics)

Features

• Real-time temperature monitoring using the DHT22 sensor.

• Real-time humidity monitoring.

• Displays sensor readings on a 16×2 I2C LCD.

• Outputs live data to the Serial Monitor for debugging and logging.

• Low-cost and energy-efficient ESP32-based solution.

• Continuously updates environmental readings in real time.

• Simulated and tested using the Wokwi online simulator.

Hardware Components

• ESP32 Development Board

• DHT22 Temperature and Humidity Sensor

• 16×2 I2C LCD Display

• Jumper Wires

• USB Cable (for programming the ESP32)

Software Components

• Arduino IDE

• ESP32 Board Package

• DHT Sensor Library

• LiquidCrystal_I2C Library

• Wokwi Simulator

• C++ (Arduino Programming Language)
